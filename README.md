# What is this?
A custom Hide and Seek game mode for Rain Meadow.<br>
Currently this is only playable in Arena (Single room), but in the future, Story will be supported too (Multiple rooms).

# Other Information
If you are curious about this mod make sure to check out the [docs](docs/) folder first.<br>
Most non-obvious types and members have fairly comprehensive inline documentation too.

If you would like to contribute anything, use the gitflow branching strategy and follow code styles as best as you can.<br>
General IDE settings and Resharper inspections are provided by the [.editorconfig](.editorconfig).
